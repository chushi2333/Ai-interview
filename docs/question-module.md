# 题库模块说明

## 业务定位

- 题库和题目属于官方内容，不是用户投稿内容。
- 普通用户不能创建、修改、删除题库和题目。

## 角色语义

- `USER`：普通用户
- `ADMIN`：会员
- `SUPER_ADMIN`：管理员

## 权限规则

- 题目、题库、题库题目关系的写操作只允许 `SUPER_ADMIN`
- 题目列表、题库列表、题库详情、题库下题目列表对所有登录用户开放
- 题目详情接口对所有登录用户开放，但会员题详情只允许 `ADMIN` 和 `SUPER_ADMIN` 查看

## 当前实现约定

- 题目支持难度字段 `difficulty`
- 题目支持会员可见字段 `is_member_only`
- 题库默认公开，不区分会员可见
- 列表接口不区分会员题，详情接口区分会员题

## 开发约定

- Service 层可以直接接 DTO，避免 Controller 里传过长参数列表
- Controller 层继续使用清晰的 DTO 命名，如 `questionCreateDto`
- 业务代码保持直白，避免当前阶段过度抽象
- 只在必要位置补简短注释
